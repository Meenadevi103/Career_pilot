# Schemas Layer (`backend/app/schemas/`)

This directory contains Pydantic v2 data models defining the data contracts for:
1. **Request Schemas**: Validating incoming payloads from the frontend.
2. **Response Schemas**: Serializing and filtering data sent back to the client (`model_config = ConfigDict(from_attributes=True)`).
3. **AI Output Schemas**: Strictly parsing and validating JSON generated by Gemini before persistence (Project Rule 3).
